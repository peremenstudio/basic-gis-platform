# Basic GIS Platform

This repository contains a basic GIS platform with:
- A React frontend (with Leaflet) for interactive map display and layer toggling
- An admin dashboard for uploading, editing, and deleting GeoJSON layers
- A Node.js/Express backend for serving and managing GeoJSON data

## Structure
- `/frontend` - React app (map and admin)
- `/backend` - Node.js/Express app (API for layers)

## Quick Start
Instructions for running and deploying both frontend and backend will be provided.
